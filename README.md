# PuliGo

PuliGo è un'applicazione web per la gestione operativa delle imprese di pulizie.

Permette di gestire:

- Appalti
- Dipendenti
- Turni
- Assegnazioni del personale
- Statistiche e riepiloghi
- Utenti e ruoli
- Dati operativi aziendali

## Stack tecnologico

- React
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel
- GitHub
